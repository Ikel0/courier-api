    ce que le projet travaille

    Une petite API, mais les bons réflexes.

    01

    Contrat avant code

    Le format d'entrée et les états de réponse sont des décisions produit, pas un détail d'implémentation.

    02

    Idempotence explicite

    Une même clé d'opération ne doit pas créer deux livraisons lorsqu'un client réessaie.

    03

    Erreur qui aide

    Un statut HTTP est accompagné d'un code, d'un message et d'un contexte actionnable.

    04

    Trace pour opérer

    Chaque demande possède un identifiant de trace afin d'aligner client, logs et support.
